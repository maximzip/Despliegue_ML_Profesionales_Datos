Does a data professional use AI?

A classification API that estimates whether a person uses artificial intelligence tools at work based on demographic and professional information from the Stack Overflow Developer Survey 2025.

Try the prediction → View endpoints
Professional profile → classification model → AI usage estimation

Simple to understand, easy to integrate.

The API receives an individual's features and returns a prediction. The project's goal is to estimate training needs across a workforce.

01 / INPUT

Professional Profile

Age, education, employment status, experience, role, organization size, work mode, industry, country, and salary.

02 / MODEL

LogisticRegression

A classification model processes the input features to estimate the target variable.

03 / OUTPUT

Prediction

The API allows querying individual profiles or processing an entire workforce to obtain counts and percentages.

Endpoints

Four routes cover the web interface, individual predictions, and batch workforce processing.

GET/Main landing page presenting the project and API documentation.
GET/appWeb interface to test individual and batch models interactively.
POST/predictSingle-person prediction via JSON payload.
GET/predict_getSame prediction via URL query string, useful for quick testing.
POST/predict_batchBatch evaluation of a full workforce and summary of non-AI users.

Make a request

For an individual prediction, send all 12 required fields as JSON to /predict.

curl -X POST https://<your-app>.onrender.com/predict \ -H "Content-Type: application/json" \ -d '{"Age":"25-34 years old","EdLevel":"...","Employment":"Employed", "WorkExp":4.0,"LearnCodeChoose":"...","DevType":"Data scientist", "OrgSize":"100 to 499 employees","ICorPM":"Individual contributor", "RemoteWork":"Remote","Industry":"Software Development", "Country":"Spain","ConvertedCompYearly":45000}'

Categorical values must match the options supported by the API. The web interface provides selector dropdowns with the exact expected values.
